# Mod portal upload kit

Everything that goes on the [mod portal page](https://mods.factorio.com/mod/too-many-buildables):

| File | Where it goes |
|---|---|
| `too-many-buildables_0.11.3.zip` | **Upload a new version** (the mod itself) |
| `too-many-buildables-description.md` | **Information** tab |
| `summary.txt` | **Summary** field |
| `gallery/` | **Images** tab, in number order (`01-overview.jpg` is the thumbnail) |

The description's videos and screenshots load from this repo's `media/` folder.
